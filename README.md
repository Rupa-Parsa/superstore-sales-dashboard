Superstore Sales Dashboard
Project Overview

This project analyzes Superstore sales data using Power BI. The dashboard provides insights into sales performance, profitability, regional performance, product performance, and loss-making sub-categories.

Key Business Insights
Technology is the highest-selling category.
The West region generates the highest sales.
Sales show an overall increasing trend from 2014 to 2017.
Copiers are the most profitable sub-category.
Tables are the largest loss-making sub-category.
Bookcases and Supplies also generate negative profit.
The Canon imageCLASS product is the top-selling product among the Top 5 products.
